# Interactive Polling Platform - Graduation Project

A real-time interactive presentation and audience engagement web application built as a graduation project.

## 🚀 Live Demo
[View Live Application](https://project-brqcl.vercel.app)

## ✨ Key Features
- **Interactive Presentations:** Real-time polling, word clouds, and Q&A sessions during lectures/gatherings.
- **Live Audience Engagement:** Instant response visualization for participants.
- **Responsive UI:** Clean, modern, and user-friendly interface for both desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Deployment:** Vercel
